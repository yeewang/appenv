# AppEnv icon

Three flat, overlapping teal, blue and white rings represent independent app environments on a navy rounded square. The transparent PNG is the source artwork. `scripts/build-icon.sh` generates standard macOS sizes; `scripts/build.sh` bundles the ICNS before signing.

Created using the built-in imagegen tool with the previous dimensional icon as reference. Prompt: Redesign the provided AppEnv macOS icon in strictly flat vector-like style. Preserve three overlapping rounded-square rings, teal, blue and pale white, on a solid navy rounded square. Solid uniform fills, crisp geometric edges, no gradients, shadows, bevels, glow, lighting, texture or 3D. Center on a square transparent canvas. No text or logos.
